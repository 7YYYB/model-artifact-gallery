# 模型作品库

包含**公开作品社区**和**本地私人作品库**两个独立版本。两者的数据不会自动互通。

## 公开作品社区

入口：**https://7YYYB.github.io/model-artifact-gallery/**

- 任何人均可浏览和上传，**无需登录或注册**。选择 HTML、SVG、PNG、JPEG、WebP 或 GIF 自包含文件，填写标题、模型和公开署名，确认内容可公开后发布。
- 单文件最大 **1 MiB（1,048,576 字节）**，前端和数据库均校验真实内容大小；不设每账户作品数、全站作品数或每小时上传次数限制。模型选项包含51个预置模型及自定义名称。
- 作品、提示词和署名均公开，署名和模型名称由投稿者填写，**不代表身份或模型来源认证**。请勿上传个人隐私、密钥或侵权内容。
- **首页直接显示作品**：卡片自动加载真实缩略预览，HTML 动画可直接播放，无需先点击；点击卡片可放大查看。接近屏幕时加载，离屏释放预览，并复用有限内容缓存以减少流量和 CPU 消耗。
- HTML/SVG 在隔离 iframe 中运行，可执行自身脚本，但不能读取社区页面或联网。请内联 CSS/JS，并将图片嵌入文件；依赖 CDN、外链字体或 fetch 的作品无法完整预览。隔离不能防止耗费 CPU 的脚本，不要在作品内输入密码或支付资料。
- 访客没有修改和删除数据库记录的权限。需要撤回作品时，请通过仓库 Issues 向管理员提供作品标题和具体信息（不要附私密资料）；管理员核对后在 Supabase 后台删除。内容目前没有发布前人工审核。
- 应用不设数量限额，但 **Supabase/GitHub 的存储、流量、请求及免费套餐额度仍然有效**；超过平台额度可能影响服务。免登录开放上传可能产生垃圾内容和额外资源消耗，管理员应定期检查 Usage 和清理违规内容。

### 社区部署与维护

- `docs/` 是 GitHub Pages 发布目录，来源为 `main` 分支的 `/docs`；不是根目录的本地版 `index.html`。
- `cloud-schema.sql` 定义表、RLS及上传/内容读取 RPC，在 Supabase SQL Editor 执行。匿名访问只能读取作品元数据并调用受校验的上传/预览函数，不能直接写表或删改作品。
- `cloud-config.js` 和 `docs/cloud-config.js` 只包含项目 URL 与浏览器可公开的 Publishable key。此公钥不是管理员凭据；安全边界依赖数据库权限/RLS。**禁止提交 secret、service_role、数据库密码或个人访问令牌。**
- 根目录 `cloud.html`、`cloud.js`、`cloud.css` 是社区源文件；更新时同步到 `docs/index.html`、`docs/cloud.js`、`docs/cloud.css`（站点首页链接保持 `./index.html`）。前端使用版本固定的 Supabase JS 浏览器组件，经 CDN 加载。
- 不要发布 `data/`、私人作品、数据库备份或 `HANDOFF.md`。上传到社区不会写入 GitHub 仓库，而是写入 Supabase 数据库；GitHub 只托管网页和源码。

## 本地私人作品库

以下其余说明适用于本地版。原生 HTML/CSS/JavaScript + Python 标准库 + SQLite，不需要 npm、云端账号或第三方依赖。

## 启动

双击 **启动作品库.cmd**。需要 Python 3.9+ 和 Windows `py` 启动器（本机已确认 Python 3.13.16）。浏览器自动打开，默认地址 `http://127.0.0.1:8765`。如果该端口被其他程序使用，启动器依次尝试 8766–8775。已经运行同一个作品库时，会直接打开已有服务。

保留启动窗口，关闭窗口或 Ctrl+C 会停止服务；已保存作品不会丢失。不要直接双击 index.html：作品库需要本地 API 服务。

也可在此目录运行：

```powershell
py -3 start.py
# 自定义端口
py -3 server.py --port 8780 --open
```

## 使用

- **模型名称**：下拉预置 [Arena Agent 榜单](https://arena.ai/leaderboard/agent) 的51个模型，按榜单顺序保留 High/Max 等版本名称（2026-10-06读取，榜单显示日期2026-10-02）。这是本地快照，不会自动联网同步。另列出已使用的其他模型，可选“自定义模型…”手动输入。添加和编辑都能选完整名单，预设不会计入已有作品统计。
- **添加作品**：选择模型，导入一个或多个 HTML、SVG、PNG、JPG、GIF、WebP 文件；每个文件最多10MB。多个文件自动使用各自文件名作为标题，按同一个模型归档。
- **粘贴 HTML**：支持完整 HTML 源码，也能去掉 Markdown 的 html 代码围栏。
- **管理**：模型自动分组；搜索标题、模型、来源、标签、提示词和笔记；按类型筛选、时间或评分排序；支持折叠模型组、收藏和 0–5 星评分。
- **预览**：卡片动态预览，点击打开大图/网页；可关闭列表动态预览减少资源消耗。屏幕附近的卡片才加载 iframe。
- **编辑**：修改名称、模型、分类、来源、标签、提示词和笔记。要替换作品源文件，请新增一条作品，再自行删除旧条目。
- **下载原作**：详情面板可下载原始 HTML 或图片。下载后的 HTML 不受作品库沙箱保护，只在信任代码时单独运行。

## 保存与备份

所有作品原文和元数据保存在本目录的 `data/library.sqlite3`，不是浏览器缓存。清除浏览器缓存不影响作品。删除作品前会要求确认。

**导出备份**会导出全部作品（包括被当前筛选隐藏的作品、原始内容、标签、评分和笔记）。右侧向下箭头导入该 JSON 备份，采用追加方式生成新 ID，不覆盖现有作品；重复恢复会产生副本。单次 JSON 恢复最多 100MB。

大量作品或完整迁移：先停止服务，再复制整个项目目录，尤其 `data` 文件夹（包含可能存在的 WAL/SHM 文件）。不要在运行时只复制一个 SQLite 主文件。

## 隔离与限制

- 服务只绑定 `127.0.0.1`，不开放局域网。不包含账号、多用户、云同步或自动调用模型。
- 作品 HTML 运行在隔离 iframe 中，允许自身脚本，不能访问父页面/作品库数据。CSP 默认禁止外网、子框架、表单提交和外部资源。
- 建议导入**自包含单文件 HTML**，CSS/JS/SVG 内联，图片使用 data URI。依赖 CDN、外链字体、fetch 或相邻资源文件的作品需要先转换为单文件，否则预览会缺少内容。此限制不是自动联网修复。
- SVG 图片用图片模式展示；需要脚本运行的 SVG 请放入 HTML 后导入。
- 来源和模型名称由你填写；网站不推断实际生成模型，也不会伪造测试结果或评分。
- iframe 隔离不能阻止高负载脚本占用 CPU；请只导入可信内容，大量动画时关闭动态预览。

## 开发

- `server.py`：HTTP、SQLite、数据校验和沙箱策略。
- `index.html` / `style.css` / `app.js`：界面和交互。
- `start.py` / `启动作品库.cmd`：一键启动。
- `verify.py`：标准库接口验证，使用临时数据库，不污染正式作品。

```powershell
py -3 verify.py
```
